# 🛍️ ShopSphere – E-Commerce Website

**ShopSphere** is a modern, responsive e-commerce website designed to provide users with a smooth and user-friendly online shopping experience. It allows users to explore products, view product details and manage their shopping cart.

This project was developed as part of my **Thiranex Internship** to strengthen my front-end web development skills and gain practical experience in building real-world web applications.

## 🌐 Live Demo

Visit ShopSphere https://shopsphere-ecommerce-aqsaq.netlify.app/

## 📸 Project Overview

ShopSphere features a clean and attractive clothing-store-inspired design with a responsive layout, intuitive navigation, and interactive shopping functionalities.

## ✨ Features

- Responsive and user-friendly design
- Product listing and browsing
- Individual product details
- Add to cart functionality
- Shopping cart management
- Product categories
- Attractive product cards and navigation

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layouts
- **JavaScript** – Interactive functionality and DOM manipulation
- **Font Awesome** – Icons
- **Git & GitHub** – Version control and project hosting

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder:

   ```bash
   cd ShopSphere
   ```

3. Open `index.html` in your browser or use the Live Server extension in VS Code.
